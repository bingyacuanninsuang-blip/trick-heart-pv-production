# 建议制作流程

| 阶段 | 产物 | 验收重点 |
| --- | --- | --- |
| 锁定输入 | 原媒体哈希、帧率、帧数、角色设定 | 原曲、造型、署名和保留区域明确 |
| 拆分镜头 | 镜头表、姿态与表情事件表 | 入场、转头、接住、放开和遮挡边界 |
| 设计图层 | 每个实例的来源与遮挡顺序 | 手、硬币、牌、杯、花、家具、动物、文字各有来源 |
| 难镜头样片 | 持物、镜像动作、帘幕、移动框 | 正常速度、半速、边界逐帧 |
| 原画生产 | 采用 PNG、生成记录、注册锚点 | 身份、结构、动作、接触和裁切边缘 |
| 批量合成 | 声明修改区间、逐帧记录 | 复用基准，排除误选与旧轮廓 |
| 视觉检查 | 问题清单、前后对照 | 同类镜头回归，状态变化连续 |
| 导出验证 | 正片、音轨校验、最终解码抽帧 | 完整时长、音轨、字体、标签与目标版本 |
| 归档 | 素材哈希、代码、经验、恢复说明 | 采用与弃用区分，输入依赖明确 |

原画负责人物结构；程序负责原画整体注册、跟踪、遮罩、颜色与图层合成。几何阈值、色彩阈值和帧率必须按下一片重新确定。

历史案例更早的记录见 [原制作指南](history/production-guide.md)。本轮补充的经验以 [v7–v11 返修总结](production-lessons.md) 为准。难镜头先行有实际检查方法支持，但未量化其能节省多少工时或生成额度。
