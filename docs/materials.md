# 素材目录与来源

原工程运行时优先加载 white-sailor 角色库，另有 paired-v5、paired-v6 的修订原画。因此保存这些库，而不是把早期角色素材目录全部复制。

- original-adopted/white-sailor：历史角色素材库。它包含用于不同姿态的原画及记录；不是声明其中每个候选都被最终影片采用。具体状态以生成清单为准。
- original-adopted/paired-v5、paired-v6：帽子、手部及场景修订资产。
- revisions/v7：手势、兔子遮挡、吹气动作、辫子等本地采用素材。
- revisions/v8：袖口、背面头发、拿牌手等采用资产。
- revisions/v9：拿杯子的手和脖子/下巴原画。
- revisions/v10：23 秒动作复用、暖肤色面板、署名文字层及采用来源。
- revisions/v11：完整沙发睡眠与醒来姿态底板。
- registration：手部原画裁切及整体注册框。
- reference：用户提供的角色造型/配色参考。
- records：生成、采用、复用及成片校验记录。历史记录中提到的弃用候选不因此变成采用资产。

material-origins.json 记录复制目的，file-manifest.json 记录当前仓库文件尺寸与 SHA256。记录中的本机绝对路径已脱敏。历史提示词和实际生成记录按原样保留语义；缺失的完整提示词不凭印象补写。

未包括原音轨、原 PV、全片 PNG 缓存、临时 MP4、依赖二进制及 Windows 系统字体。此仓库用于公开分享制作经验与素材；图片、角色和音乐不适用代码许可证。
