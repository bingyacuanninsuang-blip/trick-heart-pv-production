# 制作经验：从返修问题反推流程

## 1. 手部先验收结构，再验收线条

多次局部补指没有解决无名指、小指的根部与弯曲位置。问题不止是指头数量：掌骨连接、拇指方向、关节弯折和手腕朝向需要作为一只完整的手检查。用户允许换动作后，复用了更稳定的完整手势。

24–25 秒最终沿用 23 秒的已采用动作。左右手镜像时，手与袖口一起变换，以手腕/袖口锚点整体注册，避免局部拉伸手指。镜像决定姿势和拇指侧；屏幕左边或右边不能直接等同于角色左手或右手。

## 2. 硬币和持物接触需要独立所有权

硬币由原片逐帧提供，保留出现、部分露出及完整可见的时间。第一次只复制金色核心，黑色轮廓被截断，还带回旧手套边缘；修订后把完整轮廓纳入独立道具实例。

牌、杯子和花束的手指要么由联合原画确定接触，要么有明确的前指、道具、后指顺序。回贴原片道具时不能把旧手或第二套轮廓一并恢复。

## 3. 颜色相近不代表同一物体

黄色既可能是杯子，也可能是旧袖口、花瓣或装饰；白色既可能是皮肤高光，也可能是头发、衣服、眼白或动物。颜色阈值只能给出候选像素，再用区域、连通实例、边界和面积确定所有权。

不要直接扩大肤色阈值。v11 调整颈部深阴影时，较宽阈值误选了粉色花瓣边缘；增加通道关系和实例面积约束后，花瓣颜色得以保护。最终仍需看成片抽帧，不能只检查遮罩数量。

## 4. 肤色应作为角色统一色板

早期过度使用接近白色的色板，脸、脖子和手虽能统一，却显得苍白；矩形区域分别调色还会出现硬边。v10 最后编辫子面板、v11 三个特写改用暖肤色，并保留腮红与阴影。

v11 参考值为亮部 RGB [255,232,219]、阴影 [244,203,188]。这些数值针对本片，不能不看原画就套到其他角色。以未调色的采用原画确定完整肤色实例，可以避免旧浅色遮罩漏掉颈部深阴影。

## 5. 角色设定要覆盖所有视角

前面的麻花辫不能自动搬到背后；背面镜头、转身、片尾和裁切特写都要分别检查。衣服要检查完整袖口，动物耳朵要检查与头的连接。只验收正面一张设定图不足以保证全片一致。

## 6. 家具接缝需要完整底板

沙发断层来自只覆盖中部的多边形：中间是生成原画，两侧是原片底图，灰色、坐垫纹理和线条接不上。v11 使用完整沙发实例覆盖左右扶手、靠背、坐垫和右脚，并保留前景狗、歌词、装饰和帘幕的时间关系。

扩大遮罩后还发现帘幕开场的暗红色块：帘幕占据大部分画面时，按当前帧统计背景会误选帘幕色。固定镜头的底板背景应取无遮挡参考帧，再把帘幕作为独立前景恢复。

## 7. 视频结束不等于音轨已写完

实际导出中，视频帧数限制使尾部少写了音频包。解决方法是先完成视频轨，再把完整原音轨独立、无限制地 stream-copy 重封装；重封装阶段不用视频帧数限制或 shortest。

同时比较音频压缩数据哈希和 PCM 解码哈希，并进行严格完整解码。只看播放器显示的总时长不能证明音轨完整。

## 8. 修改证据必须对应最终文件

修改范围使用左闭右开整数帧区间；每轮记录基准文件哈希，未修改帧复用原缓存。每次修订都生成原速/半速同步对照，标签写明左右来源。

人工检查记录只声明实际看过的关键帧、片段或完整播放范围。自动全解码负责文件有效性，不能证明手部解剖、画风和遮挡关系正确。图像模型重跑不保证像素一致，必须保存采用原画。
