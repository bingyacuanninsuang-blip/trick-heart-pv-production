# Trick Heart PV — 制作经验与素材库

制作署名：**GPT-6 × 虹夏天使在我家**。

本仓库保存双角色 PV 的制作方法、v7–v11 修订经验、人物原画与姿态差分、注册信息，以及最终导出验证证据。目标是让下一支有限差分 PV 有可检查的参考流程。

## 从这里开始

1. [制作经验](docs/production-lessons.md)：左右手、持物、头发、肤色、家具接缝与音轨截断的实际案例。
2. [制作流程](docs/workflow.md)：镜头、原画、图层、审阅和交付的推进顺序。
3. [素材目录](docs/materials.md)：哪些是采用资产、历史库、参考图及注册信息。
4. [复用与恢复](docs/reproduction.md)：可独立使用的工具，以及历史工程的外部依赖。
5. [下一支 PV 检查表](templates/next-pv-checklist.md)。

## 已验证的交付

v11 为 1920×1080、24 fps、3768 帧、157 秒。完整解码通过，原音轨的压缩数据哈希与 PCM 解码哈希一致。本轮 318 帧发生像素修改，其余 3450 张无损输入帧与 v10 逐字节一致；这不等于重新编码 MP4 的其他帧字节完全相同。

最终 v11 MP4 SHA256：

`20b47261345073a6cacec9762143d3ac230dab70756996df89cc3919ba6478f7`

这里只保存制作经验、素材和证据。原 PV、原曲、完整交付视频、逐帧缓存和运行库不进入仓库。复现完整成片需要另行准备有权使用的输入与历史无损基准帧；不能把本库描述成开箱即用的全片重建器。
